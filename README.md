# Retech - Projeto Flask

Este é um projeto de e-commerce desenvolvido com Flask, incluindo autenticação, gestão de produtos e carrinho de compras.

## 🛠️ Instalação

1. Instalar dependências:
   ```bash
   pip install -r requirements.txt
   ```

2. Criar a base de dados:
   ```bash
   python database_setup.py
   ```

3. Iniciar a aplicação:
   ```bash
   python main.py
   ```

## 📌 Funcionalidades

- Registo/Login/Logout de utilizadores
- Página de perfil do utilizador
- Listagem e detalhes de produtos
- Carrinho de compras funcional
- Página 404 personalizada

## 🚀 Tecnologia

- **Backend:** Flask + SQLite
- **Frontend:** HTML, CSS, Bootstrap (template Retech)
